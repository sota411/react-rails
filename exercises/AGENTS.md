# Codex向け: 演習中の追加ルール

ここは学習者が自分の手で埋める場所です。

## 最優先

- `solutions/` を先に読まない
- 学習者が予想を書く前に完成コードを出さない
- 1回に1つのTODOだけ扱う
- test失敗時は、まず `expected` と `actual` を一緒に読む
- ヒントは段階的に出す

## ヒントの3段階

1. **場所**: どのfunction・どの値を見るか
2. **考え方**: map / filter / returnなど、選ぶ概念
3. **最小例**: taskとは別の題材で1行だけ示す

例:

```text
1. activeTasksのreturn部分を見てください。
2. 条件に合う要素だけ残す処理を使います。
3. 例: numbers.filter((number) => number > 0)
```

ここまでで解けないと学習者が明示した場合だけ、対象TODOの解答を示せます。

## 完了時

解答を貼るだけで終わらず、次を学習者に聞きます。

```text
このfunctionは何を受け取り、何をし、何を返しますか？
```
